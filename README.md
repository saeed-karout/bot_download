# 🤖 MasterDown — بوت تنزيل الفيديو لتيليجرام

بوت تيليجرام لتنزيل الفيديو والصوت من أكثر من **1800 موقع**، مع اختيار الجودة
وعرض الحجم والزمن المتوقع لكل خيار، ونظام اشتراكات ولوحة إدارة كاملة.

---

## ✨ المزايا

**للمستخدم**
- 🎬 اختيار الجودة من قائمة تعرض **الدقة • الحجم • الزمن المتوقع** قبل التنزيل
- 📊 شريط تقدّم حيّ أثناء التنزيل (النسبة، السرعة، الوقت المتبقي)
- 🎵 تحويل إلى MP3 بجودة 192k مع بيانات الأغنية
- ⚡ إرسال فوري للروابط المُنزَّلة سابقاً (كاش `file_id`)
- 📦 تنزيل عدة روابط في رسالة واحدة
- 🔗 وضع مضمّن (Inline) — يعمل داخل أي محادثة
- 🎁 تجربة مجانية ونظام إحالة

**للمالك**
- 💎 خطط اشتراك بحدود جودة/عدد/حجم/مدة قابلة للضبط
- 💳 دفع عبر شام كاش وسيرياتيل كاش مع تأكيد الأدمن بضغطة
- 📊 إحصائيات، أداء المنصات، سجل الأخطاء، بث جماعي، حظر
- 🍪 رفع ملفات الكوكيز من داخل تيليجرام
- 🩺 فحص صحة السيرفر وتثبيت الأدوات تلقائياً

## 🌐 المنصات المدعومة

يوتيوب (فيديو/شورتس/ميوزك) · تيك توك · إنستغرام (ريلز/ستوري/منشورات) ·
سناب شات · فيسبوك · إكس/تويتر · ثريدز · ريديت · بنترست · تويتش · فيميو ·
ديلي موشن · ساوند كلاود · لايكي · كواي · بيليبيلي · VK · وأكثر من 1800 موقع

## 🚀 التثبيت

```bash
git clone https://github.com/saeed-karout/bot_download.git
cd bot_download

python -m venv venv
source venv/bin/activate        # ويندوز: venv\Scripts\activate

python setup.py                 # يثبّت المكتبات + ffmpeg + Deno + PO Token
```

ثم انسخ `.env.example` إلى `.env` واملأ القيم:

```bash
cp .env.example .env
```

```env
BOT_TOKEN=توكن_البوت_من_BotFather
ADMIN_ID=معرفك_الرقمي
```

وشغّل:

```bash
python bot.py
```

## ⚙️ المتطلبات الخارجية

| الأداة | لماذا | بدونها |
|--------|-------|--------|
| **ffmpeg** | دمج الفيديو مع الصوت، تحويل MP3 | الجودات فوق 720p و MP3 معطّلة |
| **Deno** | حل تحديات JavaScript ليوتيوب | **يوتيوب يعيد صفر صيغ قابلة للتنزيل** |
| **PO Token Provider** | توكن يطلبه يوتيوب | فشل متكرر على يوتيوب |

`python setup.py` يثبّتها جميعاً تلقائياً. ويمكن تثبيتها لاحقاً من داخل
البوت بأمر `/installtools`، ومتابعة حالتها بـ `/health`.

## 📤 حد الرفع

Bot API الرسمي يحدّ رفع الملفات بـ **50 ميغابايت**.

لرفع حتى **2000 ميغابايت** شغّل
[Local Bot API Server](https://github.com/tdlib/telegram-bot-api) ثم أضف:

```env
LOCAL_BOT_API=http://127.0.0.1:8081/bot
```

يقرأ البوت القيمة ويكيّف كل الحدود والرسائل تلقائياً.

## 🍪 الكوكيز

إنستغرام وفيسبوك يتطلبان كوكيز جلسة صالحة. صدّرها بإضافة
**Get cookies.txt LOCALLY** بصيغة Netscape، ثم **أرسل الملف للبوت كمستند**
وأنت أدمن — يتحقق منه ويحفظه تلقائياً.

التفاصيل في [`cookies/README.md`](cookies/README.md).

> ⚠️ استخدم حساباً ثانوياً. كوكيز إنستغرام تنتهي كل ٢–٤ أسابيع.

## 🛠️ أوامر الأدمن

| الأمر | الوظيفة |
|-------|---------|
| `/health` | حالة ffmpeg و Deno والكوكيز والقرص |

## 🗂️ البنية

```
bot.py                  نقطة التشغيل وتسجيل المعالجات
config.py               الإعدادات (كلها قابلة للضبط من .env)
database.py             SQLite مع ترحيل تلقائي للمخطط
handlers/
  ├─ start.py           الترحيب والقوائم
  ├─ download.py        الرابط ← الجودات ← التنزيل ← الإرسال
  ├─ subscription.py    عرض الخطط
  ├─ payment.py         طرق الدفع والإيصالات
  ├─ admin.py           لوحة الإدارة
  ├─ growth.py          التجربة المجانية والإحالة
  └─ inline.py          الوضع المضمّن
services/
  ├─ platforms.py       سجل المنصات وإعداداتها
  ├─ extractor.py       فحص الرابط وبناء قائمة الجودات
  ├─ downloader.py      محركات التنزيل المتعاقبة
  ├─ media_tools.py     ffmpeg و Deno و PO Token
  ├─ errors.py          ترجمة الأخطاء لرسائل مفهومة
  ├─ tier_manager.py    الخطط والحدود
  └─ expiry_checker.py  انتهاء الاشتراكات
utils/                  أدوات مساعدة ولوحات الأزرار
```

عند فشل المحرك الرئيسي يجرّب البوت تلقائياً `gallery-dl` ثم `instaloader`
ثم التنزيل المباشر قبل أن يعلن الفشل.

## ⚠️ تنبيهات

- **لا ترفع `.env` أبداً** — يحتوي توكن البوت. `.gitignore` يمنعه.
- **لا ترفع ملفات الكوكيز** — هي بمثابة كلمة مرور حسابك.
- شغّل **نسخة واحدة فقط** — تيليجرام يسمح باتصال `getUpdates` واحد لكل توكن.
  البوت يمنع النسخ المكرّرة بقفل تلقائي (`python bot.py --force` لاستبدال نسخة عالقة).
- تحقق من سياسة الاستخدام لدى مزوّد الاستضافة — بعضهم يمنع خدمات تنزيل الفيديو.
- احترم حقوق النشر وشروط استخدام المنصات.
